# RSSビュー

画面下の「RSS」タブで記事を読みます。「ページ」タブでは従来の登録ページ閲覧を利用できます。ページ設定をまだ済ませていなくてもRSSタブを利用できます。

## 使い方

1. RSSタブ左上の「フィード管理」を開き、RSSまたはAtomのフィードURLを入力して「追加」を押します。一般のWebページURLからフィードを自動検出する機能はありません。
2. 記事一覧は新しい記事順です。フィード選択、検索、「未読のみ」で絞り込めます。
3. 記事を開くと既読になります。リンクはアプリ内ブラウザで開きます。リンクがない記事はフィードの要約を表示します。
4. 記事をスワイプして既読／未読を変更できます。右上のメニューから表示中の記事をまとめて既読にできます。
5. 下に引くか右上のメニューから記事を更新します。フィード管理で行をスワイプすると、確認後にフィードを削除できます。

## iCloudと保存

フィード一覧と既読状態を同じApple Accountの端末間で同期します。記事本文や取得結果は同期せず、各端末で取得してキャッシュします。オフラインでは最後に取得したタイトル・要約を表示します。記事のWebページ閲覧には通信が必要です。

登録・削除はフィード単位、既読・未読は記事単位で保存日時とリビジョンを比較して統合します。別々の記事を別端末で読んでも、両方の変更を保持します。同じ記事への競合は新しい変更が優先されます。削除の記録を保持して、オフライン端末からフィードが復活するのを防ぎます。

- フィード登録は100件まで、取得する記事は1フィードあたり最新の取得結果から最大200件です。
- 既読・未読の変更履歴は最近1,000件を同期します。それより古い記事は未読に戻ることがあります。履歴削除の境界日時も共有して、古い端末から履歴が復活するのを防ぎます。
- iCloud Key-value storageの容量は既存の登録ページ同期と共用します。容量不足の場合は画面に案内し、変更を端末内に保持します。
- Apple Accountの変更通知を受けた場合は旧状態のローカルバックアップを取り、新アカウントの状態へ切り替えます。旧アカウントの一覧を新アカウントに自動転送しません。
- 同期は即時ではありません。起動・前面復帰・更新時およびiCloudの変更通知で反映します。

## 検証

RSS 2.0 / RSS 1.0 / AtomをXMLParserで解析します。外部エンティティ解決を無効にし、サイズ・深さ・リンクのスキームを制限しています。

追加テストはRSS/Atom解析、安定した記事ID、CDATA、日時、相対リンク、不正入力、並行する既読変更の統合、削除、履歴の上限、アカウント変更、画面遷移とURL入力エラーをカバーします。

実機2台の確認手順:

1. 同じApple AccountでiCloudを利用している2台で本バージョンを起動する。
2. 片方でフィードを追加し、もう片方のRSSタブで反映と記事取得を確認する。
3. 別々の記事を両端末で既読にし、どちらの既読状態も共有されることを確認する。
4. 未読に戻す、フィード削除、オフラインで既読にしてから再接続する操作も確認する。

参考仕様: [Apple iCloud Key-value storage](https://developer.apple.com/documentation/foundation/nsubiquitouskeyvaluestore)、[RSS 2.0](https://www.rssboard.org/rss-2-0-11)、[Atom](https://www.rfc-editor.org/info/rfc4287/)。

## OPMLの取り込み

「RSS」→「フィード管理」→「OPMLをインポート」から、ファイルアプリやiCloud Driveの `.opml` / `.xml` ファイルを選択します。

- 入れ子のフォルダ内の `xmlUrl` も読み取ります。フォルダ階層は保持せず、フィード一覧へ追加します。
- 同じURLのフィードはスキップし、既存のタイトル・既読状態を保持します。
- 取り込み時の通信は不要です。登録後に記事を取得し、接続できないフィードも登録を保持します。
- 追加件数、重複、不正URL、100件の登録上限によるスキップ数を表示します。
- ファイルは5MB以下に対応します。壊れたXMLやOPML以外のファイルでは登録内容を変更しません。
- 取り込んだフィード一覧は通常の追加と同じiCloud同期の対象です。

仕様参照: [OPML 2.0](https://opml.org/spec2.opml)。

## RSSのないWebサイトの記事を読む

「RSS」→「フィード管理」の取得方法で「Webサイト」を選び、ニュース・ブログなどの記事一覧ページのURLを追加します。記事を開く／既読・未読を切り替える操作はRSSと共通です。

- HTMLの記事カード、見出しリンク、JSON-LDの記事情報から、同じサイトの記事タイトル・リンク・要約・公開日時を抽出します。
- HTMLだけで見つからない場合は、一時的なWebビューでJavaScriptを実行し、生成された記事一覧を読み取ります。このWebビューは永続的なログイン情報やCookieを共有しません。
- 公開日時が得られる記事は新しい順、日時がない記事は取得ページの掲載順で表示します。元ページで新着順になっている一覧を登録してください。
- 自動抽出で見つからない場合は「自動抽出で見つからない場合」を開き、記事リンクまたは記事カードのCSSセレクタ（例：`article h2 a`）を指定できます。
- サイトの取得方式・URL・CSSセレクタと既読状態はiCloud同期の対象です。すべての端末で対応版を利用してください。
- 記事のURLを基に同じ記事を識別し、タイトルが変わっても既読状態を維持します。広告・ナビゲーション・外部サイトへのリンク・追跡用クエリの重複を除外します。
- サイトの構造変更、ログイン必須ページ、アクセス制限、表示に長時間を要するページでは取得できない場合があります。エラー時は前回取得した記事を保持します。
- ページ取得は既存の「更新」と同じタイミングです。アプリが閉じている間の定期巡回は行いません。

HTML解析には[SwiftSoup](https://github.com/scinfu/SwiftSoup) 2.13.9を使用し、MITライセンスをアプリに同梱しています。

検証は静的HTML、JSON-LD、重複・不要リンク、日時順、日時のない記事の掲載順、CSSセレクタ、既存RSSデータとの互換性、JavaScript生成記事、キャンセル、登録画面をカバーします。実サイトのHTML取得も独立した検証プログラムで確認しています。
